# 史莱姆亚马逊设计skill 1.0

面向 Codex 的 Amazon 主图与 A+ 设计工作流。把产品资料、竞品展示分析、参考选择、风格小样、正式生图和质量检查连成一个可以持续推进的任务。

**当前版本：1.0.0** · [下载正式版](https://github.com/knight9629/slime-amazon-design-skill/releases/tag/v1.0.0)

## 这套 Skill 做什么

- 先确认真实产品信息、外观结构和生产范围，再确定图片卖点。
- 分开寻找画面与排版参考，支持“喜欢 / 一般 / 不喜欢”、全部换一批、保留喜欢重找。
- 生成 A/B/C 风格小样，由使用者选择方向，然后在同一个任务中继续生产。
- 支持主图、Basic / Premium A+、桌面与移动端范围，以及 Premium 轮播槽位规划。
- 检查产品一致性、文案、画面质量、文件尺寸和原图比例；未通过的槽位继续返工。

1.0 延续此前 0.7.0 的设计流程，并修复版本升级时的旧评分器分流兼容问题。

## 包含内容

| 核心 Skill | 用途 |
| --- | --- |
| `amazon-ai-design-workflow-orchestrator` | 从资料与需求开始统筹全流程，普通主图/A+请求使用这个入口 |
| `amazon-image-production-runner` | 承接已经确认的产品信息、风格和生产计划，执行正式生产与导出 |

这是两个核心 Skill 的公开源码快照，包含各自的脚本、模板和规则文件。公开仓库不包含真实商品项目或历史开发备份。

## 运行条件与辅助依赖

需要可读取本地文件、浏览参考图片并调用生图工具的 Codex 环境，以及 Python 3.10+、Pillow。正式产品生图优先使用原生图片引用；不可用时，仅可按 Skill 规定使用视觉上下文回退。无法传递真实视觉输入时应明确报告阻塞。Skill 本身不提供图像模型、模型额度或第三方 API 凭据。

以下辅助 Skill **未包含在本公开包**中。已有相应且可验证的项目材料时，可以从适用阶段继续；从零完整运行应先准备对应依赖：

| 辅助 Skill | 何时需要 |
| --- | --- |
| `product-reference-composer` | 选择 `MINIMAL_LIBRARY` 路线，需建立白底产品参考图时 |
| `amazon-competitor-creative-research` | 缺少当前产品的竞品卖点与展示逻辑文档时 |
| `amazon-product-selling-point-brief` | 缺少当前产品信息与卖点优先级文档时 |
| `amazon-creative-style-sampler` | 补齐风格推荐材料，或接续使用该 Skill 生成的风格样图时 |

安装后先让 Codex 检查辅助 Skill 与工具是否可用。缺少依赖时应列出所缺入口，不能把安装两个目录视为从零全流程已经就绪。

## 安装

下载 Release 中的 ZIP 并解压，或克隆当前源码（功能版本仍为 1.0.0）：

```bash
git clone --branch main --depth 1 https://github.com/knight9629/slime-amazon-design-skill.git
```

将 `skills/` 下的两个完整目录安装到 Codex 的技能目录。macOS / Linux 常用路径为 `~/.codex/skills/`；已有同名目录时先备份再更新。

也可以打开解压目录，让 Codex 执行：

```text
请检查这个史莱姆亚马逊设计skill 1.0 包，把 skills 下的两个核心 Skill 安装到我的 Codex 技能目录。
如果已有同名 Skill，先备份；同时检查 README 列出的辅助 Skill 和生图工具依赖，告诉我实际可运行的范围。
```

完成安装后重新打开任务，使技能列表重新加载。

## 开始使用

建议先准备真实产品照片、参数/说明书、品牌与站点信息，以及可用的竞品链接或图片材料。

```text
使用 $amazon-ai-design-workflow-orchestrator，基于这个文件夹的产品资料，
为美国站制作主图和 A+。请先检查素材、确认产品事实与生产范围，再按流程推进。
```

只做 A+ 时可以明确说：

```text
使用史莱姆亚马逊设计skill 1.0，只做 A+。先检查我的真实产品资料，
让我选择参考和 A/B/C 风格，再继续正式生产。
```

图片数量、A+类型、语言及桌面/移动端范围以每次任务确认结果为准。最终导出要求原图比例与目标完全一致，再等比例调整像素；内容通过不代表尺寸与文件检查也已通过。
